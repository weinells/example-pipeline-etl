ExamplePipeline Table Documentation

Each page summarizes what the table captures and lists the schema below that summary. The pages are organized by pipeline stage so the ETL flow is easy to follow.

Raw source

  • src_customer_device_map.csv - Source customer-to-device mapping table for the HFC network. It connects each customer to a modem and router identifier.
  • src_modem_signal.csv - Raw modem signal telemetry captured from the HFC access network.
  • src_cmts_signal.csv - Raw CMTS-side signal telemetry for the cable access path.
  • src_router_signal.csv - Raw router-side signal telemetry associated with the customer gateway.
  • src_modem_mtr.csv - Raw modem telemetry table that carries the MTR service-health measurement used later in target generation.

Interim ETL

  • trn_cmts_signal.csv - Join-ready CMTS telemetry enriched with customer and router identifiers.
  • trn_modem_signal.csv - Join-ready modem signal telemetry enriched with customer and router identifiers.
  • trn_router_signal.csv - Join-ready router signal telemetry enriched with customer and modem identifiers.
  • trn_modem_mtr.csv - Join-ready modem telemetry reading enriched with customer and router identifiers.

Feature assembly

  • features_unified.csv - Unified modeling feature table formed by joining the four interim ETL outputs.

Target engineering

  • target_bad_service.csv - Synthetic binary target table indicating whether a customer is labeled for bad service.

Modeling dataset

  • gtm_v1.csv - Good-to-model training table that combines the unified features with the synthetic target.

Scoring output

  • predictions_v1.csv - Inference output table containing the model predictions for bad service.
