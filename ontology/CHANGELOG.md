# Ontology Change Log

## 1.0.0 - 2026-08-10

Initial release of the ExamplePipeline ontology.

- Added the human-readable ontology, formal OWL ontology, and logical-asset mapping.
- Defined customer, hardware, telemetry, feature, label, prediction, rule, and model vocabulary.
- Defined customer-to-modem and modem-to-router ownership cardinalities.
- Defined router-to-modem and modem-to-CMTS ancestor topology.
- Mapped the current pipeline datasets and columns to ontology concepts.
- Documented rule-derived labels, persisted-model predictions, and their provenance.
